# 仓库同步说明

## 远程

| 远程名 | 地址 | 用途 |
|---|---|---|
| `upstream` | `https://atomgit.com/openJiuwen/agent-runtime.git` | 官方仓库，只拉取 |
| `origin` | `https://github.com/songhaowei666/agent-runtime.git` | 自己的 GitHub，只推送 |

查看当前远程：

```bash
git remote -v
```

## 分支

- `main` 只跟官方 `upstream/main` 对齐，不在上面写自己的改动。
- `dev` 放自己的改动，跟踪 `origin/dev`。`git push` 更新自己 GitHub 上的 `dev`。

## 日常：拉取官方并合进 dev

```bash
git checkout main
git pull upstream main

git checkout dev
git merge main
git push
```

第一步把官方更新合进本地 `main`。第二步把本地 `main` 合进 `dev`。最后的 `git push` 把更新后的 `dev` 推到自己的 GitHub。

## 提交自己的改动

在 `dev` 上修改、提交、推送：

```bash
git checkout dev
git add <要提交的文件>
git commit -m "说明这次改了什么"
git push
```

`server/.env`、`mac依赖/`、`learn-agent-runtime` 已在 `.gitignore` 中，不会被提交。
